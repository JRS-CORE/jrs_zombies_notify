# jrs_zombies_notify

> Zombie growl sound alerts used by jrs_zombies

![RedM](https://img.shields.io/badge/RedM-cfx-b22222) ![Lua](https://img.shields.io/badge/Lua-5.4-2c2d72) ![License](https://img.shields.io/badge/license-GPL--3.0-blue) ![Version](https://img.shields.io/badge/version-1.1.0-informational)

## Requirements

Standalone, no framework needed.

## Install

1. Download this repository and put the `jrs_zombies_notify` folder in your server `resources` folder.
2. Add `ensure jrs_zombies_notify` to your `server.cfg`.

The easiest way is to install the whole framework with the txAdmin recipe from the main repo.
